# Contributing

Thank you for helping improve Auto Emulator Update.

- Keep emulator-specific download rules in JSON manifests where possible.
- Prefer official project APIs, official download sites, or official GitHub releases.
- Do not add piracy sources, BIOS/firmware/key downloads, or copyrighted system files.
- New resolver behavior should include tests.
- Cross-platform changes should avoid OS-specific assumptions in the Core project.
